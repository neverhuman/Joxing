## Ordered implementation

1. Register four factors before evaluation: native 2 ms / no equipment, native 2 ms / gloves,1 ms / no equipment,1 ms / gloves. All retain 20 ms controller cadence and the same scheduled-restored actor/normalizer. Set `frame_skip` 10 or 20 to preserve physical control timing. No 100 Hz decoder change in this factorial. Use explicit variant IDs/model/observation/action hashes; do not call the 1 ms variant GPU or bitwise native parity.
2. Build variants with MuJoCo MjSpec from canonical assets. Add two 0.283 kg glove bodies, spherical inertia `0.4*m*0.062**2`, native hand-relative placement consistent with BalanceModel and equipment collision shells. Preserve every native body's mass/inertia and every actuator/tendon/equality; do not fold glove mass into native hands. Verify exactly 0.566 kg added, 700 muscles retained,85/85 coordinate dimensions and no fixed-root/equality support or gravity compensation. A no-equipment 2 ms adapter must reproduce the v6 task before variants are admitted.
3. Solve the hard observation problem explicitly: adding child bodies can shift later MuJoCo body IDs, while the saved trajectory's xpos arrays retain the original body ordering. Build a `ReferenceBodyMap` from canonical names to trajectory indices and variant model IDs. Actual positions use variant IDs; reference positions use original trajectory indices. Validate each keypoint and all 3601 ordered features against native `_get_obs` at identical states in the no-equipment variant. Never index the old trajectory with new body IDs or zero-fill a missing feature. Joint/actuator order must be checked by name too. Keep float32 sigmoid arithmetic identical to v6/upstream.
4. Extend the NativeTask construction seam without changing its default path/behavior. Snapshot model/variant/observation hashes, actual last observation, reference phase, normalizer, RNG and cached inputs. Existing v6 tests remain valid. Test missing/duplicate names, permuted body IDs, equipment inertia/ownership, timing 10 vs 20 substeps, support sampling, unknown surfaces, no per-step pose writes and pending/contact continuation. Preserve the exact failed Mac compiled-contract check; any future portable comparison needs its own explicit criteria, not a rewritten v6 pass.
5. Qualify short source-host physics/action/observation replay first, including the no-equipment 2 ms v6 oracle. Controls remain physical muscle excitations; visual changes cannot hide dynamics changes. Benchmark full policy+normalization+physics+telemetry at 1 and 4 workers, one thread each, on an inspected host. Record raw throughput and invalids; no extrapolation from the old 16-worker stance benchmark.
