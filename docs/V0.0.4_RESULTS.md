# v0.0.4: gravity and feedback learning results

Date: October 26, 2026. Public repository: [neverhuman/Joxing](https://github.com/neverhuman/Joxing). This release implements and runs the native-gravity feedback platform carried forward from v0.0.3's planning. **It does not establish learned standing or boxing competence.** [Execution plan](V0.0.4_PLAN.md), [raw evidence and policies](../artifacts/v0.0.4/).

## Delivered implementation

- One native-root MS-Human-700 athlete under `[0,0,-9.81]` gravity: 85 qpos, 85 qvel, 700 muscles/activations and 42 equalities. Segment inertia and muscle parameters match upstream; two gloves add exactly 0.566 kg.
- Reset-only equality/velocity projection and gravity preparation, with all preparation corrections logged. All 32 development resets meet the bilateral-foot, <=2 mm penetration and <1e-8 equality-error checks. No pose writes, fixed root or gravity compensation during evaluated trajectories.
- Signed floor support, force/persistence-based motor failures, 138 named muscle groups and 1,023 real feedback observations. Hand targets are reset positions, not a raised boxing guard.
- Bounded CPU SAC, immutable protocols, atomic progress/checkpoints, all paired development evaluation rows, fault receipts and complete evaluation snapshots at control boundaries.
- Twelve finite 0.8-second directional root probes at 2/1/0.5 ms. These short probes do not exclude every root singularity or qualify complete boxing collisions.
- **63 tests pass on Mac and Linux**, including actual SAC updates, checkpoint reload, time-limit bootstrap, signed momentum/support, push scheduling, malformed-state rejection and sorted-JSON replay. Ruff passes. Existing strike/scoring tests remain intact.

## Replay and numerical limits

The independent audit caught a real defect: sorted JSON reordered right/left/non-foot support channels during restore. The release fixes channels by semantic order and tests the sorted-file roundtrip. This affects restored observation decoding, not the live training observation path. Malformed snapshot state, clocks, shapes and unknown fields fail before mutation.

Linux continuation of both exported policies on the preselected scenario 30000 matches the original entire integration state exactly. Mac independently validates checkpoint hashes, all 64 raw rows, paired starts, summaries and repeatability of local restore (zero repeated-continuation error).

**Linux-to-Mac closed-loop full-state parity fails the declared 1e-5 tolerance.** Initial/final full-state max errors are 2.115e-4 / 2.412e-3, dominated by solver warmstart; qpos errors are 4.707e-8 / 8.102e-7 and qvel errors 1.316e-6 / 1.600e-5 in coordinate units. Both fall outcomes and terminal ticks match. The failed criterion and its nonzero audit exit are preserved; tolerances were not relaxed. This is not a general cross-platform deterministic simulation claim.

Snapshots cover control boundaries, including during a scheduled push. Arbitrary interruption inside a Python control step and complete learner resume with replay buffer/RNG restoration remain unimplemented. Force values remain simulation predictions; no empirical injury or punch-force calibration is claimed.

## HPC findings

The post-run benchmark uses the actual final policy, gravity physics, support, cached resets and inference, with three repeats per worker count. Compile/load/warmup are separate. It excludes optimizer updates and the game referee.

| CPU workers | Median control transitions/s |
|---|---:|
| 1 | 65.71 |
| 2 | 131.81 |
| 4 | 240.52 |

This is approximately 3.66x scaling from one to four workers for that workload. Actual SAC learning after warmup is much slower (roughly 17–18 control transitions/s). Scaling simulator workers alone will not resolve the measured learner bottleneck. See [benchmark](../artifacts/v0.0.4/benchmark.json) and [execution accounting](../artifacts/v0.0.4/execution-summary.json) for the different denominators.

An in-flight checkpoint at 29,424 transitions had entropy coefficient 0.4652. At one prepared reset, 32 sampled actions produced a mean entropy reward term around -107, versus a maximum motor reward of 0.025 per control transition. This points to an entropy/reward-scale issue worth testing, **not a causal ablation result**. Save the [diagnostic](../artifacts/v0.0.4/learner-diagnostic.json) rather than assuming more compute will fix the objective.

No GPU simulation or GPU learner was used. Shared-host services and unrelated jobs were untouched. The training job and benchmark finished; no run from this iteration remains active. Evaluation preparation adds 6,400 derived substeps beyond the worker-preparation counter; diagnostics/tests/audits are separate. We do not present a partial counter as an exact grand total.

## Reproduction and the next gate

From a recursive checkout, install `uv sync --extra dev --extra viz --extra motor`. Run:

```bash
uv run pytest -q
uv run joxing balance-probe --out runs/v0.0.4/reproduction-probe
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run joxing train-stance --out runs/v0.0.4/reproduction-pilot --steps 100000 --workers 4 --seed 73 --wall-s 1800 --eval-count 32
uv run python scripts/verify_balance.py --run artifacts/v0.0.4/pilot --out artifacts/generated/balance-audit.json
uv run python scripts/report_balance.py --run artifacts/v0.0.4/pilot --out artifacts/generated/balance-report --video
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run python scripts/benchmark_balance.py --run artifacts/v0.0.4/pilot --out artifacts/generated/balance-benchmark.json
```

Prefix commands with `rtk proxy` on the configured local Mac. The audit returns nonzero when the strict cross-platform criterion is missed; inspect its separate accounting, same-host restore and cross-host parity flags. A new wall-capped training reproduction can complete a different number of transitions; reproduce the published fixed-policy evaluation from its exported bundles. Exact initial/final hashes and all attempts are in [pilot metadata](../artifacts/v0.0.4/pilot/).

The next research step is a **new, preregistered development protocol**, preserving this failure: compare motor reward/entropy scaling; profile optimizer batches, architecture and update ratio; measure a GPU neural learner against CPU while keeping CPU physics; then consider a feasible muscle-driven posture teacher. Use equal declared budgets and report every attempt. Do not tune on final evaluation IDs. These are proposed experiments, not existing CLI flags or measured fixes.

Only after >=16/32 five-second development survivors with zero invalids should the larger three-seed proof run. Its >=61/64 quiet stance and >=58/64 recovery criteria per seed stay unchanged. Complete anatomical collision/guard geometry, sporting foul/fall attribution, raised guard and independent reach/return remain later gates before tactical self-play. Boxing points remain head 2, torso 1, guard 0.
