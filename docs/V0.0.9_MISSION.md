## Objective and completion

Measure and improve correct rollout throughput on the actual native controller, retaining the path to simultaneous opponent-aware two-player learning. First qualify scalar versus batched inference, then use end-to-end profiling to choose CPU scaling, centralized inference or hot-path collection work. All700 muscles, physical criteria, cached features and frozen normalization remain intact. Native episodes are not boxing games; competitive learning remains disabled.

Completion requires a preregistered baseline/prototype comparison with every timing/invalid/not_run case, strict fixed-action physics/replay, verified actor/backend math contract, resource counters, source-frozen commands, independent accounting and honest result. A useful performance win is >=1.2× median full-workload throughput at equal workload/worker count and zero new validity faults. A failed optimization is a complete experiment. Non-goals: claiming100,000 games now, root/anatomy surgery, scoring changes, GPU-physics promotion, driver/service changes or buying compute.
