policies require a separately named behavior/recurrent/RNG contract.

Wrapper snapshots include the base engine/reference/cache snapshot, original
teacher inputs, held teacher/residual/command bytes and policy state. All wrapper
checks precede the base's existing atomic restore. Aggregate physics entry credit
never rewinds. At an idle boundary the last record is historical; at a just-sampled
boundary remaining20 belongs to the current sample. Midhold203 has17steps left.

Development tests use the actual intact native engine but an explicitly synthetic
actor/normalizer. They compare neutral engine/commands/reference/contact tapes to
