# H10 — Preserve pretrained balance while adding a controlled arm/guard task

Status: planned; no new pilot or outcome. Origin: prospective. Updated:2026-10-29.

- Idea: start from an actually compatible pretrained standing/locomotion motor;
  retain actor/normalizer/reference phase and all700outputs, then introduce
  explicitly owned, bounded upper-limb adaptation.
- First work: inventory real tasks/checkpoints and input/action conventions.
  Build exact zero-residual parity tests before any physical training. Specify
  muscle/group overlaps, local coordinates, limits and checkpoint/RNG ownership.
- Future gate: finite preregistered reset/task/seed battery; posture/support,
  hand target/face and exact held-command replay. Preserve every attempt and
  publish one full fixed recording per condition regardless of points.
- Stop: source/parity/budget failure, unsupported task transfer, altered native
  anatomy or external assistance during evaluated motion. Fresh full Linux
  source gate before a new scientific collector or physical pilot.
- Key risk: walking is not stationary guard. Freezing a gait clock or zeroing
  velocities changes the learned task and does not supply a validated stance.
- Current evidence: H1 short walking positive; H2 failed survival adaptation;
  H8 selected group-PD controllers lean severely. No proven adaptation win yet.
