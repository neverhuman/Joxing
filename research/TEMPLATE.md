- Registration: frozen source + protocol/hash; pending if not yet frozen.

- Faults/limits: failed attempts, missing evidence and unsupported claims.
- Decision: adopt / decline / diagnostic only / continue / stop.
- Next: smallest useful follow-up.
- Evidence: links to source, protocol, result, audit and experiment book.
