   continuing the same question; allocate the next unused ID for a new question.
2. Start from TEMPLATE.md. Record idea, falsifiable gate, scope and source/protocol

   result, faults, limits, decision and next action. Preserve negative evidence.
4. Cite exact frozen commits/protocols and receipt paths. Do not copy large tables
   or raw arrays here; do not silently update old criteria to fit an outcome.
5. Update this index, README/status/experiment book as appropriate, and commit
   the notes with the implementation/results. Research notes do not replace
   public preregistration, independent audits or required tests.

speed is not games/s; recorded history is not a policy trained to use it.
